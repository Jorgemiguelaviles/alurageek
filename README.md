Alura Geek - Loja de E-commerce
O Alura Geek foi um dos desafios mais empolgantes que enfrentei durante minha formação Frontend na Alura. Este projeto tinha como objetivo a criação de uma loja de e-commerce completa, utilizando DHTML e tecnologias relacionadas. O desafio foi proposto pelos professores com a intenção de nos ajudar a aprofundar os conhecimentos em desenvolvimento web, desde a estruturação de páginas até a manipulação de dados e interação com o usuário.

Embora eu não tenha concluído o projeto devido a novos compromissos profissionais — quando consegui meu primeiro emprego na área de programação e desenvolvimento de softwares —, o Alura Geek ainda representa uma etapa significativa no meu aprendizado e desenvolvimento de habilidades em frontend.

🚀 Sobre o Projeto
O Alura Geek é uma loja de e-commerce fictícia focada em produtos geeks. O projeto abrange desde a criação de uma interface amigável e funcional até a implementação de carrinho de compras, listagem de produtos e filtros de pesquisa.

Objetivos:
Criar uma loja virtual completa com uma interface moderna e interativa.
Praticar os fundamentos de HTML, CSS e JavaScript, aplicando conceitos de DHTML.
Desenvolver uma experiência de compra fluida e intuitiva para o usuário.
🌐 Tecnologias Utilizadas
HTML: Para estruturar as páginas do e-commerce.
CSS: Para estilização e criação de uma interface visual agradável.
JavaScript: Para manipulação de dados e criação de interações dinâmicas no site.
DHTML: Combinação de HTML, CSS e JavaScript para criar uma experiência interativa.
🎯 Funcionalidades
Catálogo de Produtos: Exibição de produtos geek, como action figures, camisetas, acessórios, etc.
Interface Responsiva: A loja é adaptada para diferentes tamanhos de tela, garantindo uma boa experiência em dispositivos móveis.

🛠️ Status do Projeto
